# RichMerchants-G1R — native ModKit port

> **Credit where it's due:** this repo is a native AngelScript port of
> **Rich Merchants More Ore - Arrows - Bolts - Configurable** for
> *Gothic 1 Remake* by **tailwindtom**
> ([Nexus Mods #161](https://www.nexusmods.com/gothic1remake/mods/161),
> v1.0.2, UE4SS Lua). The mod design, the default multipliers and every
> gameplay decision are tailwindtom's work. This port contains **none of the
> original code** — it is a clean-room reimplementation for the official G1R
> ModKit, published with attribution. If you are the original author and want
> anything changed or removed, please open an issue.

## What it does

Multiplies every trader's stock of **ore** (`ItMi_Orenugget`), **arrows**
(`ItAm_Arrow`) and **bolts** (`ItAm_Bolt`) — **default x3** — so merchants
stay useful as buyers and sellers for longer. Configurable per item (edit
three constants at the top of the script; the game recompiles on launch).

## How the native port works

All vanilla trader configs are *script* classes deriving from
`UTraderConfigBase` (`Script/Items/GenericItems/TradersGeneric.as`,
`Script/LevelScripts/TradersData.as`) and stock every item — including
chapter-gated restocks (`"StoryG1R_EnteredChapter_N"`) — through one script
helper, `UTraderConfigBase::AddTraderItemAllDifficulties(item, count, event)`.

The port is a single class using `ReplaceParentClass` (inheritance injection)
to take `UTraderConfigBase`'s place in the hierarchy. Every one of the 30
trader configs then inherits through it, and each stock entry for the three
target items is scaled before the vanilla difficulty math runs:

```
boosted = RoundToInt(RoundToInt(count * difficultyMult) * multiplier)
```

That is bit-for-bit the original's math (`floor(live_default * mult + 0.5)`
where `live_default` is the difficulty-adjusted vanilla amount). One hook
covers all traders, all chapters and all difficulty presets; no vanilla
tables are copied, and nothing outside the three item classes is touched.
The full extracted vanilla-vs-boosted table (115 stock entries, 28 traders
with ore/arrow/bolt stock; Riordian and Xardas carry none) is in
[`docs/vanilla-stock-table.md`](docs/vanilla-stock-table.md), generated by
[`tools/extract_trader_stock.py`](tools/extract_trader_stock.py).

## Behavioral differences vs the UE4SS original (read this)

The Lua mod ran outside the game and rewrote the **live** stock maps of
already-instantiated traders a few seconds after every level load. The native
port instead scales the **stock config** the game seeds traders from. Honest
consequences:

| | UE4SS original | This port |
|---|---|---|
| New game | boosted at once (runtime patch) | boosted at once (config seed) |
| **Existing save** | boosted at once | boosted when the game next (re)builds the trader's stock (world start / chapter transitions) |
| Save purity | live state patched out-of-band every ~34 s | stock produced by the game's own config pipeline |
| OnlyRaise (never reduce below current) | explicit `max(current, target)` | inherent for multipliers >= 1.0 (nothing is ever below vanilla); multipliers < 1.0 *do* reduce below vanilla |
| Debug keys F6/F7, console `rm_apply`/`rm_status`, Verbose logging | yes (UE4SS log) | not ported (no UE4SS; the game writes no script logs) |
| Config | `config.lua` | three `const float`s at the top of `RichMerchants/Script/RichMerchants/RichMerchantsStock.as` |

Not ported, by design: an in-game settings UI (a game-build bug crashes any
mod registering a settings page when a second mod is enabled — see
[docs](https://github.com/L-Sypniewski/BalancedTraders-G1R) in the
BalancedTraders repo) and the diagnostic keybinds (they only wrote to the
UE4SS log, which doesn't exist for ModKit mods).

## Installation

Steam Workshop (preferred) — or clone/copy `RichMerchants/` into the game's
`G1R/Mods/` directory and enable it in the in-game Mod Manager. Requires the
game's official mod support (ModKit); conflicts with nothing, but do **not**
stack with another mod that multiplies the same stock (effects would chain).

## Status

Compile-validated against game build `Build106_CL176207` with the calibrated
`-as-exit-on-error` harness (negative control + clean + multi-mod runs;
evidence in `RichMerchants/VALIDATION.md`). In-game stock amounts need a
human session to confirm — see VALIDATION.md for what is and isn't proven.
