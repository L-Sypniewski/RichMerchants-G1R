# NOTICE

This project is a native AngelScript (Gothic 1 Remake ModKit) port of the
**Rich Merchants** mod for *Gothic 1 Remake*.

## Original work being credited

- **Mod:** Rich Merchants More Ore - Arrows - Bolts - Configurable
- **Author:** tailwindtom (Nexus Mods)
- **Source:** https://www.nexusmods.com/gothic1remake/mods/161 (v1.0.2)

## What was taken from the original

- The mod concept and gameplay goals (multiply every trader's ore / arrow /
  bolt stock, default x3, per-item configurable, never reduce below vanilla).
- The default multiplier values (3.0 / 3.0 / 3.0) and the item scope
  (ItMi_Orenugget, ItAm_Arrow, ItAm_Bolt).
- The published behavior description, used as the behavioral specification.

## What was NOT taken

- No Lua source code, no configuration files, no assets and no text of the
  original mod are included or redistributed. The AngelScript in this
  repository was written from scratch against the official G1R ModKit.

If you are the original author and want this repository changed, renamed,
relicensed or taken down, please open an issue or contact the repository
owner.
